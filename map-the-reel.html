A link, not an app

Only the host needs Map the Reel. Everyone else votes from a web page.

Identity

No accounts — so how are votes counted once?

A name is required. The same name from another browser asks “Is that you?” before replacing the vote.

Control

Who gets to decide?

Each vote has a private host key. Only the host's app can pick the winner.

Closure

When is it over?

Voting closes the moment the plan is set. No late votes reshuffling dinner.

Follow-through

How do people actually show up?

One tap to add it to Apple or Google Calendar, and directions in the right maps app.

Live

Does the host have to refresh?

Votes stream in on their own while the host watches.

Privacy

Where does the vote live?

On a tiny server for 3 days, then it deletes itself.

Every browser

Will it look right everywhere?

Solid cards instead of blur effects that some browsers draw badly.

Accessibility

Confetti for everyone?

Celebration plays for the plan, skipped when Reduce Motion is on.

Free on iPhone. A bill on Android.

Every reel would cost money to read. That breaks the one promise the app makes, so Android waits until it can be free too.

🤖 Android friends still vote — the web link works in any browser.
